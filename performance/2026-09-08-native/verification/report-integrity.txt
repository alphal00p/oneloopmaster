INTERPRETATION LIMITS

The source verifies all three Rust outputs on the full untimed input/batch
layout before measurement; each timed evaluation computes all three, but
only the finite checksum is accumulated and recorded during Rust timing.
Fortran checks all three fixtures/batch-final outputs and its timed finite
checksum. Python checks every timed output and all three Laurent checksums
outside its timing interval. These are different measurement boundaries.
Python timing includes conversion and result allocation, but excludes input
list preparation and final result destruction. Initialization is excluded.
The CPU-affinity-controlled runs are a shared-host snapshot, not isolated
machine measurements or confidence intervals. Binary64 only is timed.

1.50627 D0 mixed ratio remains a miss despite its proximity to the target.
